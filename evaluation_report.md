# Evaluation Report

## 1. Purpose

The purpose of this project is to evaluate AI-generated responses using a structured quality assessment framework.

## 2. Evaluation Method

Each response is reviewed across six criteria:

| Criteria | Description |
|---|---|
| Accuracy | Checks whether the information is factually correct |
| Relevance | Checks whether the response directly addresses the prompt |
| Completeness | Checks whether important information is included |
| Clarity | Checks whether the response is easy to understand |
| Safety | Checks for harmful, unsafe, or inappropriate content |
| Overall Quality | Overall assessment based on all criteria |

## 3. Scoring System

Each criterion is scored from 1 to 5.

- 1 = Poor
- 2 = Needs Improvement
- 3 = Average
- 4 = Good
- 5 = Excellent

## 4. Quality Review Process

The evaluation process includes:

1. Read the user prompt carefully.
2. Review the AI-generated response.
3. Check accuracy and relevance.
4. Check completeness and clarity.
5. Review the response for safety.
6. Assign scores based on the evaluation criteria.
7. Provide a clear reason for the final assessment.
